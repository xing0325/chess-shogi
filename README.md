# 国象 × 将棋 · 9×9 融合对战


**在线试玩(GitHub Pages,同屏双人:本地对战 + 大局选将):** https://xing0325.github.io/chess-shogi/

![国象 × 将棋 · 9×9 融合对战项目概念封面](docs/assets/cover.jpg)

我从小接触棋类，喜欢不同规则带来的不同思考方式。这次想问一个很具体的问题：把国际象棋和将棋放到同一张棋盘上，它们能不能对弈？这是我最早用 Claude Code 做出的产品尝试。

**[▶ 无需登录，直接试玩同屏对战](https://xing0325.github.io/lixon/demos/chess-shogi/)**

## 怎么浏览

打开上面的试玩入口，选择“本地对战”，两个人在同一台设备轮流走子。完整版本另有联机大厅，需要独立后端；静态试玩只适合本地同屏玩法。

## 从想法到规则

我选择 9×9 棋盘来容纳将棋的布局，再尝试用额外的后补偿另一边“打入”机制带来的差异。这里最有意思的部分是设计假设：我不能只因为规则能运行，就宣布双方已经平衡。

做的过程中，问题从“棋子怎么走”变成了“这些机制相遇时怎么算”。吃子、升变、打入和胜负判断要使用同一套规则；联机时还需要服务端校验，不能让两个客户端各自说了算。因此规则引擎、界面和服务端被分开，也为规则写了自动化测试。

## 新模式:大局选将

从大局将棋的 205 种棋子里随机抽 24 种组成卡池,双方按英雄联盟职业赛的 BP 顺序禁用 / 选择 5 枚,加上固定的王将,在 5×5 棋盘上轮流布阵后对战。支持本地同屏和联机(每步 30 秒限时、断线重连)。规则、设计依据、棋子数据的来源与校验见 [docs/TAIKYOKU_DRAFT.md](docs/TAIKYOKU_DRAFT.md)。

## 当前边界

这是一款融合规则的实验作品，仍需要更多真实对局来验证平衡。王车易位、吃过路兵和将棋打步诘禁手尚未实现，会影响与标准规则的一致性。不要把它当作完整的国际象棋或将棋规则实现。
